# Dotfiles
### These are my personal config files for an Arch Linux tiling window manager environment

#### Requires:
- Git
- Yay
- Stow

#### Features:
- Hyprland
- Waybar
- Kitty
- Zsh + Oh My Zsh
- Rofi
- Arc Darkest
- Bibata cursors
- Papirus icons

```bash
git clone https://github.com/gustavawn/dotfiles && cd dotfiles && ./setup.sh
```
